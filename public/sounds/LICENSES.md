# Lesson sounds — sources and licences

All six files come from one pack.

- **Pack:** Interface Sounds 1.0, by Kenney (www.kenney.nl)
- **Source:** https://kenney.nl/assets/interface-sounds
  (download: `kenney_interface-sounds.zip`)
- **Licence:** Creative Commons Zero (CC0 1.0), http://creativecommons.org/publicdomain/zero/1.0/
- **Downloaded:** 2026-10-25

Each file was converted to mono MP3 at 96 kbps and peak-normalised to -3 dBFS. The clips are too short for integrated-loudness measurement.
